# Obelisk Double Review — v0.3 Build Gate

## Pass 1 — intent integrity

- The product answers a producer's outcome question, not merely a legal-document question.
- Parallel must be called at runtime when fresh external evidence matters.
- Gemini must be materially involved in live counterfactual generation/orchestration.
- The deterministic router must remain responsible for consequence propagation and decision math.
- The demonstration must contain a contradiction, scope failure, or other adversarial condition.
- Human authority must cause a production revision and re-verification, not an instant greenlight.

## Pass 2 — adversarial findings and repairs

| Failure mode | v0.3 response |
|---|---|
| Fixed pipeline disguised as adaptive routing | Replaced with state-dependent router; tests require repeated/skipped modes |
| Fake optimization | Explicit world metrics + Pareto set + minimum-useful-action selection |
| Scalar score overrides real objective | NATE re-enters and can reject a world that misses the deadline |
| Old evidence survives changed production | Evidence is revision-bound; historical records are excluded from active support |
| Local evidence treated as global rights | TGC builds territory-specific evidence-frame requests and routes back to PROOF |
| Cross-deliverable fix leaves trailer blocked | OBELISK creates cross-deliverable blockers and forces ECHO remap |
| Territorial edge case missed | DEVIL creates explicit territory-split constraints |
| Same source repeated as corroboration | PROOF raises source-concentration constraint |
| LLM chooses and grades its own solution | Gemini may propose; deterministic engine propagates/ranks |
| Approval treated as proof | AUTHORITY creates new production revision; PROOF runs again |
| Client fabricates an alternate world during approval | Authority references a server-issued decision ID and rejects worlds not present in that snapshot |
| Untrusted web text injected into UI | Frontend escapes dynamic evidence before rendering |
| Partner cameo | Live path calls Parallel Search; missing key returns HTTP 424 rather than fake evidence |
| Partial Gemini output silently accepted | Partial blocked-asset coverage falls back to deterministic candidates |
| Private prompt leakage | DISTILLATION emits public receipt; private prompt material is not part of the receipt |
