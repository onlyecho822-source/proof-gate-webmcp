# Release Path — Design Spec v0.3

## Problem

A media project can be technically finished while still be operationally unreleasable because rights-sensitive assets create coupled dependencies across scenes, trailers, territories, distribution deadlines, and evidence requirements.

## Product thesis

Diagnosis is not enough. Release Path asks what changes next.

> Find the smallest useful intervention that changes the blocked outcome, propagate its consequences, preserve the evidence trail, and stop at human authority.

## Cognitive modes

1. **NATE** — practical objective framing and post-optimization reality check.
2. **ECHO** — dependency/bond mapping and counterfactual consequence propagation.
3. **PROOF** — revision-bound evidence, source independence, freshness and contradiction handling.
4. **OBELISK** — structural attack on the current answer.
5. **DEVIL** — narrow search for failure-causing edge cases.
6. **TGC** — evidence-frame expansion across intended distribution territories.
7. **COUNTERFACTUAL** — bounded candidate production changes.
8. **MINIMUM** — Pareto/minimum-useful-action selection.
9. **AUTHORITY** — explicit human permission before creative mutation.
10. **DISTILLATION** — public receipt of evidence and decision state without private prompt disclosure.

## Non-linear proof

The router is state-driven, and the demo deliberately causes backwards transitions:

- OBELISK discovers cross-deliverable coupling → graph dirty → ECHO remaps.
- DEVIL discovers territorial split risk → graph dirty → ECHO remaps.
- TGC detects insufficient distribution evidence → evidence frame changes → PROOF re-runs.
- MINIMUM selects a low-edge verification path → NATE rejects it because it misses the Friday deadline → another deadline-feasible world becomes the recommendation.

## Authority/re-verification

A human approval event changes what the production is allowed to do, not what is factually proven. Applying a world therefore creates a new production revision and triggers a new evidence cycle.

## Safety / legal boundary

No mode is allowed to certify ownership or legal clearance. Status values are production decision-support states only: `HOLD`, `CONDITIONAL`, `GREENLIGHT`.
