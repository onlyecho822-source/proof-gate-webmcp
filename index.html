What this does not do

Proof Gate does not browse, hallucinate missing evidence, or convert confidence into fact. It evaluates only evidence bound to the current claim revision; older evidence remains visible in audit history but cannot leak into a new claim.

WHY WEBMCP

The webpage stops being a picture the agent has to reverse-engineer.

Without WebMCP

The agent reads labels, guesses which controls matter, scrapes state from the DOM, and tries to keep its own copy synchronized.

With WebMCP

The page exposes typed actions and state directly. Agent calls update the same evidence ledger the human sees, creating one shared workspace instead of two drifting interpretations.
